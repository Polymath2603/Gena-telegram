# Gena 🤖

> Telegram bot powered by Google Gemini AI. Precursor to Amalgam.

**Status:** Active development 🟢

A Telegram bot that uses Google Gemini for intelligent conversation, image analysis, and customizable personas.

## Features
- Chat with Gemini on Telegram
- Vision support (send images and ask questions)
- Custom personas via `/settings`
- `/clear` to reset context
- Customizable behaviour settings

## Setup
1. Set `GEMINI_API_KEY` and `TELEGRAM_BOT_TOKEN` in `.env`
2. Run: `python main.py`
